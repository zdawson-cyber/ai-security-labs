# Azure Key Vault Security & Governance Lab

## Overview
This lab was created to build hands-on familiarity with Azure cloud security concepts related to secure secrets management, identity and access management (IAM), governance controls, and audit-ready security documentation.

The lab focuses on reviewing Azure Key Vault functionality, RBAC access controls, secure configuration practices, and Azure Policy governance concepts within a personal Azure environment.

---

## Lab Objectives
- Create and manage Azure resources within a controlled lab environment
- Review Azure Key Vault security concepts and secrets management workflows
- Practice IAM/RBAC review and least-privilege access concepts
- Review Azure Policy governance and compliance concepts
- Document findings and remediation recommendations in a security-focused format
- Strengthen familiarity with Azure cloud security operations and audit readiness activities

## Lab Activities

### 1. Resource Group Creation
Created a dedicated Azure resource group to isolate cloud security lab resources and support organized resource management.

### 2. Azure Key Vault Deployment
Provisioned an Azure Key Vault instance to review secure secrets management concepts and Key Vault configuration settings.

### 3. Secret Creation & Management
Created test secrets within Azure Key Vault to review secure storage workflows and understand how secrets are managed within Azure environments.

### 4. IAM / RBAC Review
Reviewed role assignments, privileged access considerations, and least-privilege alignment using Azure RBAC and IAM controls.

### 5. Azure Policy Governance Review
Reviewed Azure Policy concepts related to Key Vault governance, compliance monitoring, and secure configuration expectations.

### 6. Security Documentation & Findings
Documented security observations, remediation recommendations, and governance considerations using audit-style reporting and remediation tracking documentation.

---

## Key Security Takeaways
- Secrets management should follow least-privilege access principles
- Azure RBAC helps reduce excessive permissions and improve governance
- Governance guardrails and Azure Policy can strengthen cloud compliance posture
- Audit-ready documentation improves visibility into remediation and security activities
- Secure cloud operations require ongoing monitoring and configuration validation
